## What testing corrected

- A 700 KB fetch limit rejected Linear’s server-rendered documentation. Increased the bounded limit to 2.5 MB.
- Empty URL fragments were counted as separate documents. Canonicalization now removes empty and nonempty fragments and queries before crawl deduplication.
- Navigation text could make an unrelated page appear OAuth-related. Extraction now prioritizes article or main content.
- The HTTP preview lacks browser `crypto.randomUUID`. Request IDs now use `crypto.getRandomValues`, which also works on that preview origin.

## Uncertainty kept visible

Effort ranges are editorial planning estimates, not measured setup durations. Approval timing is unknown unless a provider source establishes it. Provider policies, account eligibility, scopes, review exceptions, and admin settings can change; recheck sources before submitting a real app.

The initial public-doc scan cannot establish that a hypothetical app would be approved. The app labels live plans as advice, provides source evidence, and calls out the account-dependent steps explicitly.
